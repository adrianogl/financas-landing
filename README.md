# Finanças — landing page

Página de apresentação do [Finanças](https://github.com/adrianogl/financas), app de finanças pessoais
para iPhone e iPad.

HTML e CSS puros, sem build. Publicada pelo GitHub Pages a partir da branch `main`.

## Rodar localmente

```sh
python3 -m http.server 8000
```

Depois abra http://localhost:8000.
